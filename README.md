## 🌸 貼心功能與特色 (v3.0)

### 🌷 1. 清楚明瞭的 1-2-3 步驟設計
- **步驟 1 面板**：
  - 整合「古鎮居民設定」與「📥 匯入我的個人化資料」按鈕，設定完即可順暢進行下一步。
- **步驟 2 & 步驟 3 左右對稱卡片**：
  - **左半側（步驟 2）**：方便點選「選取登場同學」與「集體微調成績/次數」，與下方名冊緊密呼應。
  - **右半側（步驟 3）**：上方配置「🚀 開始最佳化運算」（支援 `Ctrl+Enter` 快捷鍵），下方提供「💾 快速備份」與「🧹 清空重設」。
- **步驟 3 雙模式分析**：
  - 左右並列【交流策略 A】（每輪 0 溢出優先）與【交流策略 B】（高戰力平滑派駐模式），方便依照手邊資源自由參考。

### 📊 2. 即時戰力與理論極限推估
- **即時數值連動**：調整親密度、精力、角色成績或次數時，上方資訊列會立即推估：
  - 初始親密度（例如：`55%`）
  - 登場規模（例如：`26 人 (78 次)`）
  - 可用總戰力（例如：`2,818,431`）
  - **🎯 理論交流上限**：以純數學模型推估的完美極限輪數（例如：`11 輪 (55% ➔ 100%)`）。
- **推估原理說明**：點選 `ⓘ` 圖示可查看演算法說明，了解實際 5 人排程與數學理論值的差別。

### 🛡️ 3. 隱私安心與操作提示
- **純前端運算**：所有計算都在您的瀏覽器本機端完成，不儲存任何個人資料。建議隨時點選【💾 快速備份】下載專屬清冊，下次開啟直接【📥 匯入】即可輕鬆還原。
- **開頁貼心提示**：每次載入頁面時，頂部「操作說明」會自動浮現 3 秒提示使用小撇步，隨後輕巧收起。

### 💾 4. 檔案備份與戰報匯出
- **支援標準檔案對話框**：點選快速備份或匯出戰報時，可透過瀏覽器儲存視窗自訂存檔位置並鎖定 `.xlsx` 格式。
- **雙模式分頁輸出**：
  - 分頁一【模式一_早期0溢出優先】：匯出策略 A 排程明細。
  - 分頁二【模式二_超高戰力平滑】：匯出策略 B 平滑排程明細。
- **浮動戰報按鈕**：試算完成後，視窗右下角會出現「📑 匯出戰報」按鈕，方便隨時下載。

### 👥 5. 57 位學生圖鑑與性別標示
- **分組快速選取**：
  - 提供 **`[ 📘 全選文組 (31) ]`** 與 **`[ 🧪 全選理組 (26) ]`** 按鈕，也可以兩者一起點選全選 57 位同學。
- **柔和清晰的視覺設計**：
  - 男生與女生卡片採用柔和的藍色與粉色系標示，選取狀態一目了然。

### 🪄 6. 批次調整成績與登場次數
- 點選已登場清單右上角 **`[ 🪄 集體微調成績/次數 ]`**：
  - **調整項目**：可批次微調 **學科成績 (戰力)** 或 **可登場次數**。
  - **條件篩選**：支援按組別（全部 / 文組 / 理組）與性別（全部 / 男生 / 女生）組合篩選。
  - **增減操作**：支援 `＋` 增加或 `－` 減少，數值最低為 `0`。

### ⌨️ 7. 便捷的鍵盤與名冊操作
- **快速跳格**：在學科成績欄按下 `Tab` 或 `Enter` / `↓` 鍵，可直接跳至下一位同學的成績欄。
- **長按連續微調**：`+/-` 按鈕支援長按連續調整，修改數值更省力。
- **拖曳調整順序**：按住左側握把圖示 `⠿` 即可自由排列名冊順序。
- **清空重設**：方便一鍵清空名冊與計算結果，恢復初始狀態。

## 📖 交流試算流程

```mermaid
graph LR
    A[步驟1: 設定居民親密度與精力 / 或匯入資料] --> B[步驟2: 選取登場同學並調整成績/次數]
    B --> C[頂部資訊列即時推估理論極限]
    C --> D[步驟3: 點擊運算按鈕或按 Ctrl+Enter]
    D --> E[檢視策略A與策略B成果]
    E --> F[下載備份清冊或匯出 Excel 戰報]
```

1. **【步驟 1】古鎮居民設定**：設定當前居民親密度（0% ~ 100%）、第 1 輪初始精力與第 2 輪起每輪精力遞增值（或點選右側「匯入我的個人化資料」直接還原）。
2. **【步驟 2】已登場角色清單**：點選「`選取登場同學`」加入同學，並填寫學科成績 (戰力) 與可登場次數（頂部資訊列同步推估總戰力與極限輪數）。
3. **【步驟 3】開始運算**：點選右上側「`🚀 開始最佳化運算`」（也可以按快捷鍵 `Ctrl + Enter`）。
4. **檢視與匯出**：參考策略 A 與策略 B 的各輪次派駐組合，點選「`快速備份`」或右下角「`匯出戰報`」下載 Excel 清單。
