## 🌟 核心特色與亮點 (v2.5 旗艦重構)

### 🏷️ 1. 1-2-3 視覺步驟動線（黃底紅字超高辨識度）
- **非侵入式漸進導引**：在介面三大核心操作區塊標題前，置入醒目的**「黃底紅字」立體步驟徽章**：
  - **頂部**：`<步驟 1>` **古鎮居民(BOSS)設定**
  - **左側**：`<步驟 2>` **已登場角色清單 (學科成績與可登場次數)**
  - **右側**：`<步驟 3>` **【交流策略A/B】最佳化交流策略成果**
- **零干擾設計**：新手 3 秒內明確掌握操作路徑；老手完全不受任何彈窗遮蔽或版面推擠，直接盲打操作。

### 🎛️ 2. 頂部高對比 App 工具列與老手極速快捷鍵
- **一鍵式功能專區**：
  - **`[ 🚀 開始最佳化運算 ]`**：長方形高亮主行動按鈕，自帶呼吸光暈微動態。
  - **`[ 🧹 重設 ]`**：鮮豔赤紅漸層，一鍵清空登場名冊與自訂設定。
  - **`[ 📥 備份 ]`**：活力翠綠漸層，下載登場角色清冊備份檔 (`.xlsx`)。
  - **`[ 📤 匯入 ]`**：天空青藍漸層，快速匯入已備份之角色 Excel 清冊。
  - **`[ 📑 戰報 ]`**：琥珀金黃漸層，匯出雙模式戰術對比 Excel 戰報 (`.xlsx`)。
  - **`[ 💬 回饋 ]`**：高反差純白漸層，線上填寫意見與問題回饋問卷。
- **⚡ 老手專屬快捷鍵**：支援 **`Ctrl + Enter` (Mac: `Cmd + Enter`)**，在表格輸入完成績後無需動滑鼠，鍵盤一鍵秒送試算！

### ℹ️ 3. 雙浮動指南（操作說明 ＋ 設定提示）全裝置雙模態
- **雙指南配置**：
  - **`[ ℹ️ 操作說明 ]`**：標頭右側新手與全站使用指南。
  - **`[ 💡 設定提示 ]`**：居民參數欄後方，提示新登場居民首輪試探與扣除次數秘訣。
- **Hover + Click 雙模態相容**：
  - **桌機懸停（Hover）**：滑鼠移入自動展開，移出時享有 `0.35s` 緩衝延遲與防斷線安全感應橋樑。
  - **點擊釘住（Click to Pin）**：點擊徽章直接固定展開，卡片右上角設有 `✖` 關閉按鈕，並支援點擊外部空白處（Outside Click）或按 `ESC` 鍵自動收合。
  - **行動端/窄螢幕自適應**：自動偵測螢幕寬度置中顯示（`width: min(92vw, 380px)`），徹底杜絕手機切邊破版。

### 🔥 4. 數據變更即時感應與「重算警示」高能反饋 (Dirty State Detection)
- **環境感知反饋**：使用者一旦修改精力、遞增、親密度、學科成績、可用次數、增刪角色、拖拉排序或批次微調，系統立即自動感應。
- **高能視覺切換**：
  - 右上角運算按鈕立即由科技藍呼吸光切換為 **🔥 金黃琥珀高能脈衝波（Alert Pulse Glow）**。
  - 按鈕文字轉化為 **「立即重新運算」**，並浮現 **`⚠️ 數值已變更（旋轉圖示）`** 動態徽章。
  - 策略面板同步標註「待重新運算」，避免玩家誤讀舊結果；點擊運算後自動恢復冷靜狀態。

### ⚡ 5. 雙模式極限交流策略（開箱 1 秒自動展示）
系統提供兩種不同演算法特徵的交流戰術，並提供左右併列雙戰報進行全方位對比：
- **【交流策略A】優先追求每輪完美 0 溢出模式**（左欄 藍色 Trophy）：
  - **適用情境**：大部分採用此策略即可。此模式會優先追求每一輪數都盡可能 0 溢出並打通最高輪數（全局 DFS 極限通關）。
- **【交流策略B】優先追求高戰力平滑派駐模式**（右欄 黃綠色 Bolt）：
  - **適用情境**：供與策略 A 對照比較用。主要追求在最高輪數下減少全局總溢出量，並適時讓高戰力角色提早出場，避免低戰力角色過早耗盡。

### 📱 6. 57 位圖鑑看板（全選文理組 ＋ 男女高辨識度）
- **一鍵全選組別**：
  - **`[ 📘 全選文組 (31) ]`** / **`[ 🧪 全選理組 (26) ]`**：支援單點全選指定組別，兩者均點擊即可**疊加全選全部 57 人**！
- **男女視覺絕對分明**：
  - **男生 (♂)**：未選中為清爽淡藍白底；選中時轉化為**皇家寶石藍立體底色 ＋ 純白字 ＋ 打勾角標 `✓`**。
  - **女生 (♀)**：未選中為甜美櫻花粉白底；選中時轉化為**鮮豔玫瑰桃粉立體底色 ＋ 純白字 ＋ 打勾角標 `✓`**。

### 🪄 7. 登場角色集體微調（戰力與次數雙維度支援）
- 點擊已登場清單右上角 **`[ 🪄 集體微調成績/次數 ]`**：
  - **微調目標**：支援集體微調 **學科成績 (戰力)** 或 **可登場次數**。
  - **多維篩選**：支援按組別（全部 / 文組 / 理組）與性別（全部 / 男生 / 女生）交叉組合篩選。
  - **增減操作**：支援 `＋` 增加或 `－` 減少，登場次數與成績保底數值均為 `0`。

### ⌨️ 8. 極速錄入體驗與流暢排版
- **Tab 垂直跳格**：在學科成績欄按下 `Tab` 或 `Enter` / `↓` 鍵，智慧垂直跳至下一位角色的成績欄，錄入極度順手。
- **長按連續加速**：`+/-` 微調按鈕支援長按連續觸發（400ms 後自動提速，按住 2 秒加速至跳 100 點）。
- **拖曳自由排序**：拖拉左側握把圖示 `⠿` 即可自由調整名冊順序。

### 📑 9. 專業美化 Excel 雙模式戰報匯出
- 支援一鍵將對比結果匯出為 `.xlsx` 檔案。
- 自動生成 **`模式一_早期0溢出優先`** 與 **`模式二_超高戰力平滑`** 雙分頁，包含自適應欄寬、微軟正黑體排版、表頭配色與溢出量色彩高亮。

## 📖 交流試算流程

```mermaid
graph LR
    A[步驟1: 設定居民親密度與精力] --> B[步驟2: 選取登場角色並調整成績/次數]
    B --> C[微調完成, 按鈕觸發待重算光暈]
    C --> D[點擊運算按鈕或按 Ctrl+Enter]
    D --> E[步驟3: 檢視策略A與策略B成果]
    E --> F[下載備份清冊或匯出對比戰報]
```

1. **【步驟 1】古鎮居民(BOSS)設定**：設定當前居民親密度（0% ~ 100%）、第 1 輪初始精力與第 2 輪起每輪精力遞增值。
2. **【步驟 2】已登場角色清單**：點擊「`選取登場同學`」加入角色，並填入學科成績 (戰力) 與可登場次數。
3. **【步驟 3】啟動最佳化運算**：點擊最右上角「`🚀 開始最佳化運算`」（或直接按鍵盤快捷鍵 `Ctrl + Enter`）。
4. **決策與匯出**：對比策略 A 與策略 B 的各輪次派駐組合，點擊「`戰報`」下載 Excel 戰術清單。
