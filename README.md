## 🌟 核心特色與亮點 (v2.1 旗艦升級)

### 🎛️ 1. 最右上角：全高亮度 App 工具列佈局
將全域操作按鈕整齊集中於頂部導航列的最右上角，預設即呈現高飽和度、高對比度的立體漸層視覺：
- **`[ 🚀 開始最佳化運算 ]`**：長方形高亮 Hero 主行動按鈕，自帶呼吸光暈微動態。
- **`[ 🧹 重設 ]`**：鮮豔赤紅漸層方塊，一鍵清空登場名冊與自訂設定。
- **`[ 📥 備份 ]`**：活力翠綠漸層方塊，下載已選登場角色清冊備份檔 (`.xlsx`)。
- **`[ 📤 匯入 ]`**：天空青藍漸層方塊，快速匯入已備份之角色 Excel 清冊。
- **`[ 📑 戰報 ]`**：琥珀金黃漸層方塊，匯出雙模式戰術對比 Excel 戰報 (`.xlsx`)。
- **`[ 💬 回饋 ]`**：高反差純白漸層方塊，線上填寫意見與建議問卷。

### ℹ️ 2. 標題後方「操作說明」Hover 浮動指南
- 主標題右側內建半透明 **`[ ℹ️ 操作說明 ]`** 徽章。
- 滑鼠移入（Hover）即平滑浮現高質感白底毛玻璃卡片，清楚提示：
  1. **Demo 與重設**：說明範例自動載入與隨時可重設或匯入。
  2. **個人資料隨手備份**：提醒設定完成後點擊備份下載 `.xlsx` 檔案。
  3. **無痕隱私與零資料儲存**：強調純本機運算、不留任何雲端個資。
  4. **快捷小技巧**：說明 `Tab` 垂直跳格、`+/-` 長按連續加速與集體微調工具。

### ⚡ 3. 雙模式極限算力引擎（開箱 1 秒自動展示）
系統提供兩種不同邏輯演算法的交流戰術，並提供左右併列雙戰報進行全方位對比：
- **【模式一】早期完美 0 溢出優先**（左欄 藍色 Trophy）：
  - 核心採用**分支上界剪枝演算法**，尋求早期輪數（1~8 輪）達成 **100% 完美 0 溢出**，並以最快速度（300ms 內）計算最高通關輪數。
- **【模式二】超高戰力平滑派駐**（右欄 黃綠色 Bolt）：
  - 核心採用**高低戰力提早平滑派駐邏輯**，避免中低戰力過早耗盡導致後期全由高戰力上陣而產生嚴重溢出浪費。

### 📱 4. 57 位圖鑑抽屜（全選文理組 ＋ 男女高辨識度）
- **一鍵全選組別**：
  - **`[ 📘 全選文組 (31) ]`** / **`[ 🧪 全選理組 (26) ]`**：支援單點全選指定組別，兩者均點擊即可**疊加全選全部 57 人**！
- **男女視覺絕對分明**：
  - **男生 (♂)**：未選中為清爽淡藍白底；選中時轉化為**皇家寶石藍立體底色 ＋ 純白字 ＋ 打勾角標 `✓`**。
  - **女生 (♀)**：未選中為甜美櫻花粉白底；選中時轉化為**鮮豔玫瑰桃粉立體底色 ＋ 純白字 ＋ 打勾角標 `✓`**。
  - 徹底告別舊版的灰黑死沉遮罩，任何狀態下性別與姓名皆清晰明亮！

### 🪄 5. 集體微調成績與次數（雙維度支援）
- 點擊左側面板右上角 **`[ 🪄 集體微調成績/次數 ]`** 呼叫浮動視窗：
  - **微調項目**：支援集體微調 **學科成績 (戰力)** 或 **登場次數**。
  - **篩選對象**：支援按組別（全部 / 📘 文組 / 🧪 理組）與性別（全部 / ♂ 男生 / ♀ 女生）交叉篩選。
  - **增減操作**：支援 `＋` 增加或 `－` 減少，登場次數與成績保底數值均為 `0`。

### ⌨️ 6. 流暢錄入體驗與快捷鍵
- **Tab 垂直跳格**：在學科成績欄按下 `Tab` 或 `Enter` / `↓` 鍵，智慧垂直跳至下一位角色的學科成績欄，跳過次數與刪除鍵，錄入極度流暢。
- **長按連續加速**：`+/-` 微調按鈕支援長按連續觸發（400ms 後自動提速，按住 2 秒加速至跳 100 點）。

### 📑 7. 美化 Excel 戰報匯出
- 支援一鍵將對比結果匯出為 `.xlsx` 檔案。
- 自動生成 **`模式一_早期0溢出優先`** 與 **`模式二_超高戰力平滑`** 雙分頁，包含自適應欄寬、表頭配色與溢出色彩高亮。

## 📖 交流試算流程

```mermaid
graph LR
    A[設定居民親密度與精力] --> B[選取登場角色或一鍵全選]
    B --> C[微調成績/次數或集體微調]
    C --> D[自動或手動啟動最佳化運算]
    D --> E[檢視模式一與模式二對比戰報]
    E --> F[匯出 Excel 戰報備份]
```

1. **古鎮居民設定**：設定當前居民親密度（0% ~ 100%）與各輪精力值。
2. **登場角色選取**：點擊「`選取登場同學`」或使用「`全選文組` / `全選理組`」快速加入。
3. **戰力與次數微調**：直接於表格輸入數值，或使用「`集體微調成績/次數`」批次調整。
4. **啟動運算**：點擊最右上角「`🚀 開始最佳化運算`」（或頁面載入 1 秒後自動運算）。
5. **備份與匯出**：點擊「`備份`」保存清冊，或點擊「`戰報`」匯出雙模式完整交流表。
